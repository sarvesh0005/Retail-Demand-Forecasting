# Retail Demand Forecasting & Inventory Optimization

A production-oriented Machine Learning project focused on forecasting retail demand and optimizing inventory decisions using statistical forecasting, machine learning, and operations research techniques.

## Project Objectives

- Build an end-to-end demand forecasting pipeline.
- Design a scalable PostgreSQL-backed data architecture.
- Perform feature engineering for time series forecasting.
- Train and evaluate forecasting models using proper backtesting.
- Estimate demand uncertainty with prediction intervals.
- Optimize inventory decisions using the Newsvendor model.
- Deploy the solution as a FastAPI service.

## Tech Stack

- Python

- Pandas

- LightGBM
